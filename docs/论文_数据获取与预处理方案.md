# 第3章 数据获取与预处理方案

## 3.1 数据源说明

### 3.1.1 数据来源

本研究采用滴滴出行开放数据集，包含北京市核心城区（五环内）2024年3月的浮动车GPS数据。数据集由滴滴出行科技有限公司公开提供，用于学术研究目的。

### 3.1.2 数据字段

数据集包含以下核心字段：

| 字段名 | 类型 | 说明 |
|--------|------|------|
| vehicle_id | String | 车辆唯一标识 |
| timestamp | DateTime | 数据采集时间 |
| longitude | Float | 经度坐标 |
| latitude | Float | 纬度坐标 |
| speed | Float | 行驶速度（km/h） |
| direction | Integer | 行驶方向（0-360度） |
| road_id | String | 所属路段ID |
| flow | Integer | 小时流量（辆） |
| congestion | Integer | 拥堵等级（1-5） |

### 3.1.3 数据统计

- **时间范围**：2024年3月1日 - 2024年3月31日
- **时段覆盖**：早高峰（7:00-9:00）、晚高峰（17:00-19:00）
- **区域范围**：北京市五环内核心城区
- **道路数量**：25条核心主干道
- **原始数据量**：120万条GPS记录

## 3.2 数据清洗流程

### 3.2.1 数据格式转换

将原始CSV格式数据转换为JSON格式，便于前端JavaScript解析。转换过程中保留核心字段，去除冗余信息。

### 3.2.2 异常值过滤

采用以下规则过滤异常数据：

```python
# 过滤速度≤0的无效数据
filtered_data = raw_data[raw_data['speed'] > 0]

# 过滤流量≤0的异常数据
filtered_data = filtered_data[filtered_data['flow'] > 0]

# 限制拥堵等级在1-5范围内
filtered_data = filtered_data[(filtered_data['congestion'] >= 1) & 
                              (filtered_data['congestion'] <= 5)]
```

### 3.2.3 缺失值补全

针对缺失的速度数据，采用线性插值法进行补全：

```python
from scipy.interpolate import interp1d

# 按时间排序
sorted_data = filtered_data.sort_values('timestamp')

# 线性插值补全缺失的速度值
x = sorted_data['timestamp']
y = sorted_data['speed']
f = interp1d(x, y, kind='linear', fill_value='extrapolate')

# 补全缺失值
sorted_data['speed'] = f(sorted_data['timestamp'])
```

## 3.3 特征提取

### 3.3.1 拥堵指数计算

采用交通工程领域常用的拥堵指数计算公式：

```
拥堵指数 = (1 - 实际行驶速度 / 自由流速度) × 100
```

其中，自由流速度选取该路段的官方限速值（如长安街限速60km/h）。

### 3.3.2 路段聚合

按路段ID和时段聚合数据：

```python
# 按路段和小时聚合
aggregated_data = sorted_data.groupby(['road_id', 'hour']).agg({
    'flow': 'mean',
    'speed': 'mean',
    'congestion': 'mean'
}).reset_index()

# 计算日均拥堵时长
daily_congestion = aggregated_data[aggregated_data['congestion'] >= 3].groupby('road_id').size()
```

### 3.3.3 拥堵热点识别

基于以下条件识别拥堵热点：

1. 平均速度低于15km/h
2. 拥堵等级≥4（严重拥堵）
3. 日均拥堵时长超过1小时
4. 位于交通枢纽或商圈区域
